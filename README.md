*   Restart your computer. This action resets your system processes and clears minor errors.
*   Disable your firewall temporarily to see if it blocks the connection. If the software works after you disable the firewall, you must add an exception for this application.
*   Ensure you use the most recent version. Check the release page regularly to find updates.
